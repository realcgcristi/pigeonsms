# Compatibility Lab 1.0

Implementations opt in through `protocol/lab/servers.json`. The lab executes public discovery, schema, version, TLS, endpoint-origin, health, error-envelope, request-ID, and latency checks every day.

Scores map to badges: gold is 100%, silver is 85–99%, bronze is 60–84%, and lower scores are failing. Every badge links to the exact machine-readable report and test timestamp. A badge never represents security certification.

Third-party clients use the normative fixtures and SDK-independent conformance runner. Implementations must publish the tested commit and protocol version with their result.
